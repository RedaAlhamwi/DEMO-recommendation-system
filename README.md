# Student Assessment Analyzer — Demo

An AI-powered diagnostic system that analyses MCQ assessment results for students and generates professional, parent-ready reports using the Anthropic Claude API.

---

## What it does

Most assessment tools tell you *what* a student got wrong. This system tells you *why*.

Each wrong answer in the question bank is tagged with the specific misconception it reveals — for example, a student who answers `x = 8` when solving `3x + 5 = 20` isn't just "wrong": they're adding 5 to both sides instead of subtracting. The system captures that distinction and feeds it into a structured report generated by Claude.

The output is a warm, jargon-free report written for parents and centre directors — not for developers.

---

## How it works

```
Student answers MCQ assessment
        ↓
Analysis engine compares answers to misconception-tagged question bank
        ↓
Topic-level breakdown: score per topic + exact misconceptions detected
        ↓
Claude API generates structured parent report (warm, actionable, plain English)
        ↓
Report delivered to centre director → shared with parents
```

---

## Features

- **Misconception-level diagnosis** — not just right/wrong scoring, but identification of the exact conceptual error behind each wrong answer
- **Topic breakdown** — performance summary across Algebra, Fractions, Percentages, Geometry, Ratio, Number, and more
- **AI-generated parent reports** — structured prompt engineering produces consistent, professional, and encouraging written reports via Claude
- **Modular question bank** — each question carries four options, each wrong option tagged with its associated misconception
- **Designed to scale** — currently covers Year 8 Mathematics; architecture supports extension to other year groups and subjects

## Running the demo

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install anthropic spacy
   python -m spacy download en_core_web_sm
   ```
3. Set your Anthropic API key:
   ```bash
   export ANTHROPIC_API_KEY=your_key_here
   ```
4. Run the script:
   ```bash
   python demo_recommendation_system.py
   ```

The script will print a topic breakdown to the terminal and then generate a full parent report via the Claude API.
